# 🏢 Modelo de Negocio B2B — KORI ALP

## Propuesta de Valor

**Kori Alp** es la primera plataforma B2B que conecta a **productores alpaqueros andinos** directamente con **empresas compradoras globales** (textiles, gastronómicas, industriales), garantizando **trazabilidad completa** y **comercio justo** desde la puna hasta el mercado internacional.

---

## Buyer Persona

### Comprador Principal: "Empresa Textil Internacional"

| Atributo | Descripción |
|---|---|
| **Nombre** | Importadora Textil Europa S.A. |
| **Sector** | Moda sostenible / Textil premium |
| **Ubicación** | Italia, Alemania, Japón |
| **Necesidad** | Fibra de alpaca certificada con trazabilidad de origen |
| **Dolor actual** | Cadena de intermediarios opaca, sin garantía de calidad ni de impacto social |
| **Presupuesto** | $20-50 USD/kg según calidad (Baby Alpaca, Suri, Fleece) |

### Vendedor Principal: "Asociación de Productores"

| Atributo | Descripción |
|---|---|
| **Nombre** | Asociación Kori Alp — Puno |
| **Ubicación** | Macusani, Carabaya, Puno (4,300 msnm) |
| **Producción** | 500-2,000 kg de fibra/año |
| **Dolor actual** | Venta a intermediarios a precios injustos, sin acceso a mercados internacionales |
| **Meta** | Conectar directamente con compradores, obtener precio justo |

---

## Diferenciadores Competitivos

1. **Trazabilidad por Lote:** Cada lote de fibra tiene su historia completa desde el nacimiento del animal hasta la clasificación de calidad.
2. **Certificaciones Integradas:** SENASA, Comercio Justo, Fibra Orgánica validadas dentro de la plataforma.
3. **Impacto Medible:** Métricas reales de familias beneficiadas, huella de carbono reducida y comercio justo aplicado.
4. **Datos Científicos:** Correlación altitud-calidad respaldada con datos (a mayor altitud, menor micraje = mejor fibra).
